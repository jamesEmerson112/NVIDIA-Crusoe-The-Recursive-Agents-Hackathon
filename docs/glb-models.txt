================ MODEL SPEC (every new file must follow) ================

Format
- glTF 2.0 binary (.glb), one file per model
- No Draco, meshopt or KTX2: the loader has no decoders
  - (adding DRACOLoader/KTX2Loader to furniture.ts would allow them)
- No cameras, lights or animations; one root node
- Name materials sensibly (oak, fabric, glass, metal)

Units, axes, origin
- Metres, real-world size (a sofa is ~2.2 m wide)
- Y up
- Front faces +Z (the side a person uses: sofa seat, cabinet doors)
  - If it can't, set frontYaw in its SPECS entry in furniture.ts
- Origin at the bottom centre, sitting on y = 0

Budget
- Hero pieces (sofa, table, bed, lamp): up to ~50k triangles, ~3 MB
- Small pieces (decor, fixtures): up to ~15k triangles, ~1 MB
- Textures: PBR, 1k (2k only for hero pieces)
  - baseColor (sRGB), normal, occlusion/roughness/metalness packed (ORM)
- Glass: KHR_materials_transmission (or low-opacity material)

Look
- Photoreal, Japandi / Scandinavian: oak, linen, warm ivory, matte black metal
- Believable manufactured products: bevels, legs, seams, cushions
- No cartoon proportions, saturated colours or mirror-gloss surfaces

Licence and provenance
- Original work made for us, or CC0 (Poly Haven, Kenney, ambientCG)
- CC-BY only with on-screen credit; no "editorial only" or unknown licences
- Add a row to frontend/static/models/CREDITS.md for every file


================ HOW A NEW MODEL GETS USED ================

1. Save as frontend/static/models/<key>.glb (key = plan type, see below)
2. Add <key> to SPECS in furniture.ts (url; frontYaw/stretch if needed)
3. Plans must contain that type, or nothing shows it:
   - Bundled plans: frontend/static/plans/*.json (furniture[].type)
   - Laurie's listings: formloop/src/plan3d.ts (listingPlan)
   - New types need adding there too; tell Laurie for formloop
4. Variants: <key>-<variant>.glb (e.g. sofa-fabric) + modelKey() rule
5. Check: /plans?quality=high&debug=1, "missingModels" should drop
