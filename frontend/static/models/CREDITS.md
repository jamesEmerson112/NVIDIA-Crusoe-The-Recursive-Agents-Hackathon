## Reproduce and inspect

Run from the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python frontend/scripts/generate-furniture.py -- all
```

Pass one or more model keys instead of `all` for a partial rebuild. The script updates `catalog.json` and the four `static/plans/models-*.json` preview collections. Each GLB is self-contained and requires no Draco, meshopt or KTX2 decoder.

Open `/plans?quality=high&debug=1` and choose a furniture collection. Use Full height to inspect wall-mounted pieces. The asset test suite verifies dimensions, pivots, budgets, registration and preview-plan validity.
